# PriceMyProject — Freelancer Pricing Calculator

Free static site. One calculator page, no backend, no ads, no accounts.

Logic: labour = hours × rate; + revision hours × rate + expenses + contingency; + profit margin; then gross up for platform fee: final = price before fee ÷ (1 − fee%). Example: keep $1,000 after 10% fee → quote $1,111.11.
